# 🗣️ 클로드에게 이렇게 요청하세요

이 홈페이지를 만들 때 실제로 쓴 요청 문장들입니다. **그대로 붙여 넣고 마지막에 "우리 반은 ○○니까 ○○로 바꿔줘" 한 줄만 더하세요.**
(홈페이지의 🛠 만드는 법 모드 → 각 카드에서도 같은 문장을 복사할 수 있어요.)

## 요청을 잘 하는 요령 (이게 핵심)
1. **구조를 먼저 말하기** — "시트가 DB, 코드는 읽고 쓰기만, 프론트→서버는 api(action) 하나" 이 세 문장을 처음에 주면 클로드가 알아서 일관되게 만들어요.
2. **시트 열 이름을 직접 정해주기** — `"과제" 시트(과제, 과목, 마감일, 설명, 링크, 공개)` 처럼. 열 이름이 곧 사양서예요.
3. **비밀은 어디에 두는지 말하기** — "인증키와 PIN은 설정 시트에만, 검사는 서버에서만".
4. **기존 코드를 따라 하라고 하기** — "기존 카드 구조(card-h / card-b)와 api() 디스패처 방식을 그대로 따라줘".
5. **한 번에 하나** — 카드 하나씩 요청하면 실패해도 되돌리기 쉬워요.

## 처음 통째로 만들기
```
구글 시트 하나에 바인딩된 Apps Script 웹앱으로 학급 홈페이지를 만들어줘.
시트가 데이터베이스이고 코드는 시트를 읽고 쓰기만 해.
카드: 오늘의 급식·시간표·학사일정(나이스 오픈API, 서버에서 호출+캐시),
오늘의 1인 1역(저장 없이 날짜로 계산), 감정 체크인(집계는 공개, 상세는 교사PIN),
랜덤 뽑기(브라우저 계산), 과제 확인(D-day, 완료 기록), 알림장.
프론트는 index.html 한 파일, 서버는 api(action, payload) 단일 진입점.
"시트 초기화" 커스텀 메뉴로 모든 시트를 예시 데이터와 함께 만들어줘.
디자인은 밝고 따뜻하게, 설정 시트의 테마색 하나로 전체 색이 바뀌게.
```

## 카드별 요청 문장

### 🍱 급식
```
나이스 오픈API의 mealServiceDietInfo로 오늘 급식을 가져오는 Apps Script 함수를 만들어줘.
인증키와 학교코드는 "설정" 시트에서 읽고, 서버(UrlFetchApp)에서 호출해서 CacheService로 6시간 캐시해.
DDISH_NM의 <br/>를 잘라 메뉴 배열로 만들고, 괄호 속 알레르기 숫자는 allergens 배열로 분리해줘.
프론트에는 날짜 ‹ › 버튼으로 전날/다음날을 볼 수 있게 해줘.
```

### 📅 시간표
```
나이스 시간표 API로 우리 반 오늘 시간표를 보여주는 카드를 만들어줘.
설정 시트의 학교급(초/중/고)에 따라 elsTimetable/misTimetable/hisTimetable 중 하나를 쓰고,
GRADE·CLASS_NM·ALL_TI_YMD 파라미터로 요청해. PERIO 순서로 정렬하고 중복 교시는 하나만 남겨.
오늘이면 현재 교시를 강조해줘.
```

### 🗓️ 학사일정
```
나이스 SchoolSchedule API로 이번 달 학사일정 카드를 만들어줘.
AA_FROM_YMD~AA_TO_YMD로 한 달 범위를 요청하고, 설정 시트의 학년에 해당하는 *_GRADE_EVENT_YN이 Y인 행사는
mine=true로 표시해서 진하게 보여줘. 토요휴업일은 빼고, 월 이동 ‹ › 버튼도 달아줘.
```

### 🧹 오늘의 1인 1역
```
"역할" 시트(역할, 설명, 고정담당, 이모지)와 "학생명단" 시트로 오늘의 1인 1역을 만들어줘.
시트에 배정을 저장하지 말고, 설정 시트의 역할순환시작일부터 오늘까지 주말 뺀 수업일 수를 세서
그만큼 명단을 회전시켜 배정해. 고정담당이 있는 역할은 항상 그 사람.
역할순환주기가 "매주"면 주 단위로 바뀌게. 내 이름을 고르면 내 역할이 강조되게 해줘.
```

### 💗 감정 체크인
```
감정 체크인 카드를 만들어줘. 8가지 감정을 이모지 버튼으로 고르고 한마디(선택)를 적어 "감정체크인" 시트에 저장해.
같은 날 같은 학생이 다시 하면 기존 행을 업데이트해.
학생 화면에는 이름 없이 감정별 막대그래프 집계만 보여주고, 설정 시트의 교사PIN으로 선생님 모드에 들어가면
누가 어떤 기분인지와 한마디를 볼 수 있게 해줘. PIN 검사는 반드시 서버에서 해.
```

### 🎲 랜덤 뽑기
```
학생명단 시트로 랜덤 뽑기 카드를 만들어줘. 탭 세 개: 한 명 / 여러 명(인원 입력) / 모둠(모둠 인원 입력).
뽑기는 브라우저에서 셔플로 처리하고, 이름이 빠르게 바뀌는 슬롯머신 효과 후 결과를 크게 보여줘.
"뽑힌 사람 제외" 체크박스와 초기화 버튼, 이모지 폭죽 효과도 넣어줘.
결과는 설정 시트의 뽑기기록저장이 Y일 때만 "뽑기기록" 시트에 기록해.
```

### 📝 과제 확인
```
"과제" 시트(과제, 과목, 마감일, 설명, 링크, 공개)로 과제 확인 카드를 만들어줘.
마감일까지 D-day를 계산해서 정렬하고 D-1 이하는 빨간 강조.
학생이 "다 했어요"를 누르면 "과제확인" 시트에 이름과 상태를 기록하고(같은 과제는 덮어쓰기), 완료 인원 수를 보여줘.
선생님 모드에서는 과제별로 학생 전체 완료/미완료 현황표를 팝업으로 보여줘.
```

### 📣 알림장
```
"공지" 시트(날짜, 제목, 내용, 고정)를 읽어 알림장 카드를 만들어줘.
고정=Y는 맨 앞에 📌 표시, 나머지는 날짜 내림차순, 최대 8개.
```
